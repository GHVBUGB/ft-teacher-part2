## 检查发现与修复

- 腾讯单词只展示准确度、流利度；句子另展示完整度。总分保留，删除重复建议分卡片。
- 音素表只展示接口能支持的音素与 0–100 准确度，删除空的识别音素和重复匹配反馈。
- 文本匹配和发音准确度分开解释，未知匹配码不会误取 JavaScript 原型属性。
- 删除上传控件、残余上传样式及过时提示。恢复流程测试页改用合成麦克风，经真实 MediaRecorder 录音，避免依赖已删除的上传框。
- 前端腾讯句子原录音上限 90 秒与后端 60 秒冲突；腾讯单词/句子现在分别于 19/59 秒自动停止，为后端 20/60 秒限制留出结束余量。未改评测接口、音频数据格式或后端上限。
- 更新评分展示断言；把所需的历史供应商评分样本放入 tests/fixtures，避免测试依赖被 Git 忽略的 artifacts。
- npm test 现在执行全部 9 个前端测试套件，原来只执行 rules.mjs。
- 补充本次新增录音提示和维度名称的英文翻译。评分公式、80 分通过线、严格度和持久化语义未改变。
