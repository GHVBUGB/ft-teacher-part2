# 考核时间与逐题统计

2026-09-20，Neon迁移004已提交。保留原始尝试记录，通过三个视图计算汇总，不覆写次数。

- enrollments：started_at、completed_at，整次培训开始及完成时间。
- speech_rounds / grammar_rounds：active_duration_ms，有效作答时长；原有created_at/finished_at计算单轮总历时。
- speech_assessments / grammar_answers：answer_started_at、submitted_at、active_duration_ms。
- speech_question_summary：全部提交、有效评分、未通过、技术失败、等待中、最高分、首次通过、已采集有效时长及采集条数。
- grammar_question_summary：按培训跨轮次统计每题答题/正确/错误次数、首次答对及已采集时长。
- stage_timing_summary：每关每轮总历时和有效时长。

NULL表示未采集，不能当0；部分尝试缺少用时，累计值只是已采集部分，需结合timed_submission_count/timed_attempt_count展示。技术失败不计答错；朗读门槛使用题目绑定版本规则。旧的无法关联题库的成绩不进入朗读汇总。
