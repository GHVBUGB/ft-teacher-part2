# 中文数据库查看

Neon 的 Tables 页面，在数据库 neondb 下，将 schema 下拉框从 `ft_training` 切换为 **中文查看**。

这里包含全部 15 张业务/系统表的中文投影，以及 3 个统计视图。原来的 `ft_training` 是程序使用的底层结构，仍保留 UUID；不能通过刷新它看到短编号。

| 类型 | 示例 |
|---|---|
| 教师、培训、题库版本 | T001、E001、V001 |
| 语法考核、朗读考核 | G001、R001 |
| 语法题、朗读题 | QG001、QS001 |
| 语法作答、朗读评分 | AG001、AS001 |
| 抽题记录、反馈 | RI001、F001 |
| 登录会话、验证码记录、规则 | S001、L001、RULE001 |

短编号来自持久化唯一序号；新增数据会自动获得新编号，删除其他记录不会重排。关联列和题目顺序采用相同编号。超过三位时不截断。

中文视图实时查询原表，不复制成绩；模拟账号仍标记为“是”。密码哈希、验证码摘要、会话凭证、校验摘要仅显示是否保存，原值仍在底层表。服务方请求号与提交 UUID 用本记录的短编号引用表示，排查原始请求仍需查询原表。

日期以北京时间显示，耗时列明确标注秒。题目正文、答案解释、规则详情不截断。短编号不作为登录凭证或权限依据。

迁移：`006_chinese_browser.sql`。验证：`server/production/tests/006_chinese_browser.sql`。不修改原始主键、外键、题目内容、评分和身份状态。
