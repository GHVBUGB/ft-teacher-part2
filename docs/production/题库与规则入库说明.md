# 三关题库与考核规则

2026-09-20 已写入项目 Neon 数据库 neondb 的 ft_training，事务提交后独立查询回读。

版本：ft-target-words-v2-round-v1-grammar-20260920。

|关卡|题库数量|每次考核|通过条件|
|---|---:|---:|---|
|单词|41|随机30|每题至少80分，30题全部通过|
|句子|58|随机20|每题至少80分，20题全部通过|
|语法|30|30|至少答对24题；错第7题提前结束|

单词采用发音分；句子采用（发音×85%＋流利度×10%＋韵律×5%）×完整度/100，保留一位小数。无有效评分不能算通过。
语法每题一次、按序作答；答错不揭示答案，允许进入下一题；失败重考打乱顺序，未完成恢复进度。
依次解锁单词、句子、语法。演示全满分不属于正式成绩。

## 表

- speech_questions：单词和句子正文、类型、补充字段。
- grammar_questions：题干、两个选项、正确选项、原始解析。原始解析按现有源文保存，没有编造额外的错误答案解析。
- assessment_rules：题量、门槛、评分和重考规则，含中文说明。
- content_versions：来源、版本和源码SHA256，避免改题影响旧成绩。
