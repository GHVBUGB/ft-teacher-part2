# 单词地图与续练约定

- 地图展示本关全部104个现有单词，可自由点选；每8个一组仅为排版，不构成新关卡。
- 点卡片进入该词独立朗读子页；可返回地图，浏览器前进/后退有效，刷新保留题目定位。
- 首页“继续”从既有成绩中寻找第一个未通过的题目。前7个通过、第8个未提交或未达80：继续第8个；第8个也通过：继续第9个。如果前面有遗漏，优先补最早未通过题。
- 已通过记录保留，达到80分标绿；仍需所有单词通过才解锁句子，句子和语法功能保留。
- 当前成绩仅保存在同一浏览器的既有存储中；未提交录音不保存。跨设备续练须后续接入统一成绩存储。
- 删除普通页面“第一、二关·发音/第三关·语法”组合页签；调试工具保留在原调试入口。
- 复用既有路径，仅以#words、#sentences、#read/<现有题目ID>定位展示页面。后端接口、参数、题目ID、数据内容版本、总分公式、保存键和对象结构均未修改。
- 独立合成测试入口tests/map-ui.html不在产品导航中，不进入生产构建；测试成绩使用独立账号与map-qa作用域。
